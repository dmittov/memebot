ПРАВИЛА ИСПОЛЬЗОВАНИЯ БОТА

Основные возможности

Этот бот позволяет публиковать мемы и изображения в канал через личные сообщения.

Как использовать бота

1. Отправка мемов в канал

Просто отправьте изображение боту в личные сообщения — бот автоматически опубликует его в канале.

Поддерживаемые типы контента:

  • Фотографии
  • Изображения
  • Медиа-файлы с подписями

2. Доступные команды

/start или /help

Показывает краткую справку по использованию бота.

/explain

Используется в групповом чате для обсуждения постов из канала:

  • Отправьте команду /explain в ответ на сообщение с фото из канала
  • Бот обработает запрос на объяснение/обсуждение изображения

3. Ограничения

Лимит публикаций:

  • Каждый пользователь может опубликовать максимум 2 мема в течение 24 часов
  • Это ограничение помогает поддерживать разнообразие контента в канале

Что происходит при превышении лимита:

  • Бот откажет в публикации
  • Сообщит о причине отказа
  • Укажет, когда можно будет отправить следующий мем

4. Статистика эмодзи

Доступна веб-страница со статистикой популярности постов по реакциям:

  • Показывает топ-10 пользователей по количеству полученных реакций
  • Обновляется автоматически
  • Учитываются все эмодзи-реакции на посты в канале

Советы по использованию

  1. Качество важнее количества — выбирайте лучшие мемы для публикации
  2. Используйте подписи — добавляйте контекст или шутки к изображениям
  3. Следите за лимитами — планируйте публикации заранее
  4. Проверяйте контент — убедитесь, что изображение корректно отображается

Вопросы и поддержка

Если у вас возникли вопросы или проблемы с ботом:

  • Используйте команду /help для базовой справки
  • Проверьте, не превышен ли лимит публикаций
  • Убедитесь, что отправляете контент в личные сообщения боту, а не в группу

BOT-NUTZUNGSREGELN

Hauptfunktionen

Dieser Bot ermöglicht es, Memes und Bilder über private Nachrichten im Kanal zu veröffentlichen.

Wie man den Bot benutzt

1. Memes in den Kanal senden

Senden Sie einfach ein Bild an den Bot in privaten Nachrichten — der Bot wird es automatisch im Kanal veröffentlichen.

Unterstützte Inhaltstypen:

  • Fotos
  • Bilder
  • Mediendateien mit Bildunterschriften

2. Verfügbare Befehle

/start oder /help

Zeigt eine kurze Anleitung zur Nutzung des Bots.

/explain

Wird im Gruppenchat verwendet, um Kanalbeiträge zu diskutieren:

  • Senden Sie den Befehl /explain als Antwort auf eine Nachricht mit einem Foto aus dem Kanal
  • Der Bot verarbeitet die Anfrage zur Erklärung/Diskussion des Bildes

3. Einschränkungen

Veröffentlichungslimit:

  • Jeder Benutzer kann maximal 2 Memes innerhalb von 24 Stunden veröffentlichen
  • Diese Beschränkung hilft, die Vielfalt der Inhalte im Kanal zu erhalten

Was passiert bei Überschreitung des Limits:

  • Der Bot lehnt die Veröffentlichung ab
  • Informiert über den Grund der Ablehnung
  • Gibt an, wann das nächste Meme gesendet werden kann

4. Emoji-Statistik

Eine Webseite mit Statistiken zur Beliebtheit von Beiträgen basierend auf Reaktionen ist verfügbar:

  • Zeigt die Top-10-Benutzer nach Anzahl der erhaltenen Reaktionen
  • Aktualisiert sich automatisch
  • Berücksichtigt alle Emoji-Reaktionen auf Kanalbeiträge

Nutzungstipps

  1. Qualität vor Quantität — wählen Sie die besten Memes zur Veröffentlichung aus
  2. Verwenden Sie Bildunterschriften — fügen Sie Kontext oder Witze zu den Bildern hinzu
  3. Beachten Sie die Limits — planen Sie Ihre Veröffentlichungen im Voraus
  4. Überprüfen Sie den Inhalt — stellen Sie sicher, dass das Bild korrekt angezeigt wird

Fragen und Support

Wenn Sie Fragen oder Probleme mit dem Bot haben:

  • Verwenden Sie den Befehl /help für grundlegende Informationen
  • Überprüfen Sie, ob das Veröffentlichungslimit nicht überschritten wurde
  • Stellen Sie sicher, dass Sie Inhalte in privaten Nachrichten an den Bot senden, nicht in die Gruppe
