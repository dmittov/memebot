# Правила использования бота

## Основные возможности

Этот бот позволяет публиковать мемы и изображения в канал через личные сообщения.

## Как использовать бота

### 1. Отправка мемов в канал

**Просто отправьте изображение боту в личные сообщения** — бот автоматически опубликует его в канале.

Поддерживаемые типы контента:
- Фотографии
- Изображения
- Медиа-файлы с подписями

### 2. Доступные команды

#### `/start` или `/help`
Показывает краткую справку по использованию бота.

#### `/explain`
Используется в групповом чате для обсуждения постов из канала:
- Отправьте команду `/explain` в ответ на сообщение с фото из канала
- Бот обработает запрос на объяснение/обсуждение изображения

### 3. Ограничения

**Лимит публикаций:**
- Каждый пользователь может опубликовать **максимум 2 мема в течение 24 часов**
- Это ограничение помогает поддерживать разнообазие контента в канале

**Что происходит при превышении лимита:**
- Бот откажет в публикации
- Сообщит о причине отказа
- Укажет, когда можно будет отправить следующий мем

### 4. Статистика эмодзи

Доступна веб-страница со статистикой популярности постов по реакциям:
- Показывает топ-10 пользователей по количеству полученных реакций
- Обновляется автоматически
- Учитываются все эмодзи-реакции на посты в канале

## Советы по использованию

1. **Качество важнее количества** — выбирайте лучшие мемы для публикации
2. **Используйте подписи** — добавляйте контекст или шутки к изображениям
3. **Следите за лимитами** — планируйте публикации заранее
4. **Проверяйте контент** — убедитесь, что изображение корректно отображается

## Вопросы и поддержка

Если у вас возникли вопросы или проблемы с ботом:
- Используйте команду `/help` для базовой справки
- Проверьте, не превышен ли лимит публикаций
- Убедитесь, что отправляете контент в **личные сообщения** боту, а не в группу
